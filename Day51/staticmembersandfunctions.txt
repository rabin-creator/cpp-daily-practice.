In Object-Oriented Programming (OOP)
 the static keyword shifts ownership of a variable
  or method from the individual object (instance) to the class itself.

 1. Static Members (Data Variables)

A static member variable is a variable shared by every instance of a class. 
Instead of each object getting its own separate copy, all objects share one single memory location.

* Memory Allocation: Allocated once when the class/program loads, not when an object is instantiated.
* Lifetime: Lives for the entire duration of the program.
* Common Use Cases: Global counters (e.g., tracking total objects created), configuration settings,
  shared constants.

example in cpp
class BankAccount {
public:
    static double interestRate; // One shared interest rate for ALL accounts
    double balance;             // Each account gets its OWN balance
};





 2. Static Functions (Methods)

A static function belongs to the class rather than any specific object. 
You can invoke it directly using the class name without creating an object instance first.

* No `this` Pointer: Static methods do not have access to an implicit `this` pointer
 because they don't operate on a specific instance.
* Access Restrictions: A static function can only directly access static variables and 
other static methods of the class. It cannot directly access non-static (instance) members
 without an explicit object reference.
* Common Use Cases: Utility functions (e.g., `Math.sqrt()`), factory methods for object creation.

For examle in cpp
class MathUtils {
public:
    static double add(double a, double b) {
        return a + b; // Operates strictly on inputs, no instance needed
    }
};

// Usage without creating a MathUtils object:
double sum = MathUtils::add(5.0, 10.0);





 Instance vs. Static: At a Glance

| Feature | Instance (Non-Static) Members | Static Members |
|         |                               |                |
| Ownership | Belongs to an individual object | Belongs to the class itself |
| Memory Creation | Created every time a new object is instantiated | Created once when the class loads |
| Invocation | `object.member` or `object.method()` | `ClassName.member` or `ClassName::method()` |
| Access Control | Can access both static and non-static members | Can only access other static members directly |
| Memory Location | Typically stored on the Heap (or Stack) | Stored in the Data Segment / Static Memory area |
